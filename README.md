Projeto Destacado: Sistema de Gerenciamento de Estoque em Python
Orgulhoso(a) de apresentar meu projeto de Sistema de Gerenciamento de Estoque, uma aplicação desktop robusta desenvolvida em Python utilizando Tkinter para a interface gráfica e SQLite para o gerenciamento de dados.
Este projeto demonstra minhas habilidades em desenvolvimento de software, persistência de dados e criação de interfaces de usuário funcionais. Principais Funcionalidades e Destaques Técnicos
O sistema foi desenhado para ser intuitivo e eficiente, garantindo o controle preciso do inventário.
Interface Gráfica Intuitiva (GUI): Desenvolvido com Tkinter para uma experiência de usuário limpa e organizada, com abas para Inventário Atual, Cadastro/Edição e Histórico.
Gerenciamento de Dados Sólido: Utilização de SQLite para persistência de dados, garantindo a integridade e o armazenamento local de produtos e registros de movimentação.
Controle de Estoque Inteligente: Implementação de Alertas de Estoque Mínimo para notificar o usuário quando a quantidade de um produto atinge o nível crítico. O sistema também oferece funcionalidades CRUD (Criação, Edição e Exclusão) de produtos.
Rastreabilidade Completa (Histórico): Todas as operações cruciais (INSERÇÃO, EDIÇÃO, EXCLUSÃO) são registradas automaticamente. O histórico detalha a data/hora, o responsável e os detalhes da mudança, proporcionando total rastreabilidade das movimentações do inventário. 
Stack Tecnológica
Linguagem Principal: Python.
Interface Gráfica: Tkinter.
Banco de Dados: SQLite3.
